# Pin To-Do 使用教程

这是一个放在 Windows 桌面上的待办工具。它的主张很简单：**任务应该待在你已经看着的地方**。
所以它有一个贴在屏幕边缘的卡盒、一片可以摊在桌面上的卡片，以及一个把时间怎么花掉的账记清楚的面板。

本教程按"先能用、再好用、最后是你的"来排。前两章就能开始用，后面是想起来再查。

## 三分钟上手

1. 装好后启动，屏幕右边缘会出现一小叠卡片——那就是**卡盒**。
2. 把鼠标移过去，卡盒会弹开成一片卡片；移开，它自己收回去。
3. 想记一件事：按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd>，输入
   `明天五点吃火锅 -日常`，回车。就这样。
   这句话里的时间和 `-日常` 会被自动认出来，前者变成到期时间，后者是分组名。
4. 想看清全貌：点卡盒上的 ▤，或者同一个快捷键打开**任务面板**。
5. 想让它长得像你：⚙ 设置 → 外观风格，十套材质任选，每套还有白天和夜里两副脸色。

## 卡盒：桌面上的那一小块

卡盒是一个无边框、透明、置顶的窗口，铺满整块工作区，但它只在自己画出来的地方接鼠标——
其余地方你照样能点到桌面和别的窗口。任务平时住在里面，按分组排好。

### 悬停、散布、钉住

- **鼠标靠近**：卡盒弹开，当前分组的卡片在旁边铺开，每张都能读。
- **鼠标离开**：卡片和卡盒一起收回去。
- **单击卡盒**：卡片散开到桌面各处，各自占一个位置。
- **拖动卡盒**：需要先在设置里解锁"拖动卡盒"。
- **钉住一张卡片**：卡片上的图钉按钮。钉住的卡片属于桌面，不属于哪个卡盒——
  收回、切换分组、关掉面板，它都留在原地。再点一次取消。

### 两种样式：卡片堆与胶囊

卡盒有两种样子，是**你选的**，不会自己变：

| 样式 | 什么时候用 |
| --- | --- |
| **卡片堆** | 方正的一叠，带分组标签、进度条和提示行，信息多 |
| **胶囊** | 两行的紧凑条，数字和全部按钮都摆得下，占的桌面只有前者的约三分之一 |

切换有两个地方，效果完全一样：卡盒菜单栏的 ◐，或者 设置 → 界面 → "卡盒改用胶囊样式"
（就在"卡盒所在屏幕"上面一行）。

### 自动缩进与所在屏幕

- **自动缩进**：一段时间没有指针靠近，卡盒自己滑到屏幕边缘外，只留一条边。
  鼠标碰那条边就出来。开关在卡盒菜单栏的 ⇤，也在设置里。
- **所在屏幕**：多显示器时可以指定卡盒待在哪块屏。设置 → 界面 → "卡盒所在屏幕"。
  只有一块屏时这里是一句话而不是按钮。

### 一键散布并置顶（全局快捷键）

默认 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd>，可在设置 → 全局快捷键里改，留空即不注册。

- **按一次**：卡盒当前分组的所有卡片散开到桌面并全部钉住。
  即使卡盒正缩在屏幕外、即使卡片层被"仅在桌面显示"挡住了，也会出来。
- **再按一次**：取消钉住并收回。

钉住期间，这一组卡片顶住"仅在桌面显示"的规则——别的窗口在前台时它们也看得见。
等你收回，或者把最后一张手动取消钉住，卡盒就把这条规则原样交还。

### 卡盒菜单栏

弹开卡盒时那一排按钮：

| 按钮 | 作用 |
| --- | --- |
| ＋ | 新建任务（也可以直接按 <kbd>N</kbd>） |
| ⟳ | 重新排布本组卡片：忘掉各处的位置，重新铺一遍 |
| ▤ | 打开/关闭任务面板 |
| ⚙ | 直接打开设置 |
| ◐ | 卡盒样式：卡片堆 / 胶囊 |
| 📌 | 把本组所有卡片钉在桌面（再点取消） |
| ⇤ | 自动缩进屏幕边缘的开/关 |
| ▣ | 隐藏桌面卡片层（托盘图标可以恢复） |
| 简 | 简化卡片：只显示标题，字号更大，不显示重要度/重复/时间/分组 |

分组名旁边的小圆点是当前分组，单击切换、双击编辑。

## 任务面板

### 打开、关闭与快捷键

- 卡盒上的 ▤，或 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd>（默认，可改）。
- 面板是一个独立窗口，标题栏可以拖，⚙ 里的"设置弹窗支持拖拽缩放"控制它能不能改大小。

### 一句话快速登记

左侧导航栏顶上那个输入框。它能认：

- **时间**：`今天` `明天` `后天` `下周三` `周五` `10月1日` `早上八点` `中午` `晚上十点`，
  以及农历日期。
- **分组**：结尾写 `-分组名`，比如 `-工作`。没写就进"临时"。
- 输入时下面会实时显示它理解成了什么（`→ 工作 · 明天 08:00`）；
  认不准的时候那行会变成警告色，你说清楚一点就行。

### 十一个视图各看什么

左侧导航从上到下：

| 视图 | 用途 |
| --- | --- |
| **仪表盘** | 自己拼的网格：时钟、统计、番茄钟表盘、今日环、备忘录、年度热力图、短列表。拖模块标题栏换位置，拖右下角手柄改大小，都按整列整行吸附并保存；标题栏 ▭ 改占宽，折叠起来收进底部一条 |
| **时间轴** | 竖向 24 小时轴。见[下一章](#时间轴一天是怎么过的) |
| **时间账本** | 今天/本周/本月的合计、按分组的占比、近十四天按当天真实发生顺序自下而上堆叠的柱子（每段穿着所属分组的颜色）、最长的五段 |
| **时间线** | 按日期分组的当日列表 |
| **月历** | 整月。**双击日期格**就地新建，日期已经填好 |
| **全部任务** | 未完成的，按日期分块，已逾期的单独顶上一栏 |
| **今日到期** / **即将到期** / **已逾期** | 三种时间视角的筛选 |
| **已完成** | 归档 |
| **分组** | 点左侧分组名进入，只看那一组 |
| **回收站** | 见[回收站](#回收站) |

台账（全部任务/分组那一屏）里：搜索框（按 <kbd>/</kbd> 聚焦）搜标题、备注和标签；
优先级下拉和排序下拉在标题栏上；**双击任务行**编辑，**单击标题**展开备注。
悬停某一行会露出计时按钮。

### 回收站

删除不再立即销毁。删掉的任务进**回收站**，在那里待 **30 天**，然后自动清掉。

- 入口：左侧分组列表最下面那一行，永远在最底——新建分组也不会把它挤走。
  后面的数字是里面有多少条。
- 每一行两个按钮：**恢复**（回到原来的分组、原来的备注、原来的到期时间）和
  **彻底删除**（需要点两次，这是唯一真正销毁数据的地方）。
- 顶上还有"清空"。
- 回收站里的任务**不算任务**：卡盒、统计、时间账本、小票、月历都看不见它，
  也不会因为它而以为你还有没做完的事。
- 30 天是按"打开时"算的，不是靠一个后台计时器。所以电脑关机一个月再开机，
  回收站会自己清干净。
- 导出 JSON 时回收站也在文件里，换机器能一起带走。

## 日期与时间

### 公历与农历

所有日期同时显示公历与农历，例如 `9月20日 · 周日 · 农历八月初十`。
重复规则里可以选择**按农历年重复**——生日、祭日这类只认农历的日子用这个。

### 时间轴：一天是怎么过的

竖向 24 小时轴，半小时一道刻度。

- **空白处按住往下拖**：登记一段时间。松手弹出一个小框，可以
  **选一个已有任务**，或者**输入新任务名**——输入新名字时旁边有个分组下拉，
  决定这条新任务落到哪一组（选了已有任务时它会置灰，因为那不改归属）。
- **拖一个块**：移动它。**拖块的下边缘**：改时长。
- **重叠的任务**自动分道并排，不会互相盖住。
- **右键一个块**：弹出小菜单，可以**删除这个任务**（进回收站），或者
  **只删这条时间记录**（任务还在）。
- 顶部一排：**‹ ›** 按周（日视图下按天）翻页、区间标题、**今天**、
  旁边一个**日期框**（直接选一天跳过去）、**周 / 日**切换。
- 右边的**锥形环**显示这一天是怎么花掉的：外圈按每 10 分钟一格上色。
  环的左右各有一个 **‹ ›**，按**天**翻页——轴面在周模式下是按周走的，环只看一天。
- 周模式下**点某一天的小标签**，环和统计就跟着切到那一天。

### 时间账本

看"时间去哪了"的地方：合计、按分组的占比、近十四天的堆叠柱（每段的颜色就是它所属分组的
颜色，顺序按当天真实发生的先后自下而上堆），以及最长的五段。

### 今日小票

把今天打印成一张热敏纸。它是一台机器，不是一张图：

- 出纸带马达声，收尾一铃。
- 左边一排自锁圆按钮：**定时 / 任务名 / 重打 / 保存 PNG / 文件夹 / 退出**，
  中间旋钮上滚轮调小时。
- **隐藏任务名**可以只留数字，方便发给别人看。
- 保存 PNG 会把整台机器一起拍进去，六种背景（含透明）可选。
- **定时出票**：只把机器和纸落在桌面旁边，自动存盘，直到你把纸撕下来。
  默认存到程序目录下的 `dataeceipts`（没有会自动新建），在设置里可以改成任何文件夹。

## 作息分组：到点自己完成

有一类事情不是待办，是**日常**：吃饭、睡觉、洗澡、喝水。你不需要被它提醒，
只需要它到点被记下来。

1. 建一个分组（或者用已有的），点它旁边的 ✎。
2. 把**"到点自动完成"**打开。
3. 往里加任务，写上时间和重复规则（比如"喝水"每天三次）。

到点了，卡片自己变成已完成——**不发通知、不播音效、不弹卡盒**。
重复任务照常滚到下一次，和你手动勾选完全一样。

想撤销：取消勾选即可；想改时间：正常编辑。这条规则只影响这个分组里的任务。

## 外观

### 十套材质，每套都有昼夜

材质不是换一套颜色，是换一套**视觉语言**：表面纹理、描边、圆角、标签字体、阴影方式都会变，
而且卡盒和桌面卡片跟着一起变，不只是面板。

| 材质 | 感觉 |
| --- | --- |
| **印刷 1971** PRINT | 终端打印件，等宽字、网点纸 |
| **餐厅 DINER** | Googie 搪瓷与铬条 |
| **群青构成 IKB** | 构成主义，2px 粗线 |
| **晨雾花园 GARDEN** | 桃红到奶油的渐变天空 |
| **指令台 RETRO** | 复古任务台，橙色安全色、螺钉法兰、扫描线 |
| **雾绿磨砂 FROST** | 薄荷灰房间上的半透明磨砂面，青色可点、大圆角 |
| **图纸 BLUEPRINT** | 黑白的磨砂玻璃：中性灰的半透明面板、发丝描边、柔和落影 |
| **紫电拼贴 COLLAGE** | 白底叠色块，电紫与钴蓝，直角 |
| **黑黄战术 HI-VIS** | 标牌漆、斜切碎片、四角瞄准框 |
| **铬黄丝网 CHROME** | 白纸大块黄，丝网标题条 |

**昼 / 夜**是每套材质里的两副配色，左下角按钮切换——不是同一套颜色变暗，是各自调过的。

### 调色实验室

设置 → 外观里可以实时覆盖任意颜色 token，白天和夜里**分别保存**。
改完记得保存；不想要了就还原本材质。

> 材质名一律按它自己的**媒介和颜色**命名，不指向任何具体作品。

## 提醒与通知

- 任务到期时发一条 Windows 系统通知，开关在设置 → "到期提醒"。
- **新建时就已经过期的任务不会提醒**。回填一条"吃了早饭"不该被追着通知：
  只有创建那一刻还在未来的时间，到点才算一次提醒。
- 作息分组（[上面](#作息分组到点自己完成)）永远不提醒。
- 提醒一次只发一条，发过就打标不再重复。

## 数据

### 导出与导入

设置 → 数据 · 维护 → **导出 JSON** / **导入 JSON**。

导出的就是整份数据文件，包括：

- 全部任务，含**所有详情**：备注、优先级、重复规则、农历、标签、已计时、钉住状态、顺序；
- 分组定义（名字、颜色、顺序、是否自动完成）；
- **回收站**里的东西；
- 计时记录；
- 桌面卡片的摆放位置；
- 你改过的**全部设置**，包括仪表盘每个模块的位置、占宽和折叠状态。

唯一不在里面的是 AI 密钥和坚果云应用密码——见下。

旁边的 **重排卡片** 只清掉桌面上的摆放记忆，让卡片重新铺一次；
**清空已完成** 和 **恢复默认设置** 会动你的数据，看清楚再点。

### 坚果云备份

用坚果云的 WebDAV 把整份数据文件传上云。设置 → 坚果云备份：

1. **账号**：你的坚果云邮箱。
2. **应用密码**：在坚果云"账户信息 → 安全选项 → 添加应用"里生成，粘进来点保存。
   它**只存进 Windows 凭据管理器**，不写进数据文件，也不会被导出或备份带走。
3. **备份目录**：默认 `pin-to-do-backup`，第一次备份会自动建出来。
4. **立即备份**：手动传一次，下面会写传到了哪里、多少字节。
5. **每天自动备份一次**：开着的话，启动时如果今天还没传过就传一次，
   文件名是 `pin-to-do-日期.json`，所以云端会留下一串按天的副本。

一天一次、只在启动时做：要的是能挺过这台机器的副本，不是一台连开一周的机器上七份同一个星期二。

### 数据文件在哪，为什么要注意它

```
<程序所在目录>\data\dashboard1971-data.json
```

程序写到哪儿就在哪儿：数据、启动日志、小票默认都在自己目录下的 `data\` 里，
运行期间不会往 C 盘写东西。只有当程序装在不可写的地方（比如没有管理员权限的
`Program Files`）才会退回 `%APPDATA%\dev.qoder.pintauri\`；第一次换到新位置时，
它会把旧位置的数据文件**复制**过去，原件留在原处不动。

一个 JSON 文件装着上面说的所有东西，每次改动即写盘（先写临时文件再改名，不会留下半截文件）。

**它没有自动备份，也没有版本历史。** 所以：

- 想折腾之前，先"导出 JSON"存一份；
- 或者把坚果云自动备份打开，这是最省心的那条路；
- 界面上"恢复示例数据"这类按钮会整片替换数据，看清楚再点。

## ✨ 让 agent 替你排

任务面板里点 ✨，说一句人话，比如"帮我把这周的两个评审都挪到下午，另外加个买猫粮"。

- 它**默认关闭**，要先在设置里填端点、模型并打开。
- 密钥存在 Windows 凭据管理器里，不进数据文件。
- 它只会**起草**：给出的改动要先在确认单上让你点头，才会写进数据。
- 时间怎么算不归它管——它把日期交给本地解析器，和[快速登记](#一句话快速登记)用的是同一套规则。
- 每一轮对话都会落一条可回放的轨迹，设置里能看到，也能导出。

## 常见问题

**卡盒不见了。** 可能被隐藏了（托盘图标可以恢复），可能缩到屏幕外了（鼠标贴边试试），
也可能设置里"桌面卡片层"被关掉了，或者"仅在桌面显示"开着而此刻有别的窗口在前台。

**卡盒挡住了我点桌面。** 它只在自己画出来的地方接鼠标。如果某个区域看着是空的却点不动，
那多半是那里确实有东西在画（比如一张正在收回的卡片）。

**我想让卡盒小一点。** 换胶囊样式。还想更小就调"卡盒大小"或关掉"按分辨率自动缩放"自己定。

**删错了。** 回收站里恢复，30 天内都在。

**换电脑。** 导出 JSON，新机导入；或者把坚果云自动备份打开，装好填上同一个账号即可。

**夜里太亮。** 每套材质都有夜间配色，左下角"昼/夜"切。还嫌刺眼就进调色实验室改那一套。

**它占多少资源。** 安装包约 1.7 MB，常驻内存约 116 MB——这是它作为桌面常驻件的全部代价。
