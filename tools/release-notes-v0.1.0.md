## Pin To-Do v0.1.0（预发布）

Windows 10 / 11 x64 的桌面任务卡片工具。标为预发布是因为版本号与安装路径以后还可能变动；功能是完整的，作者日常自用中。

### 装法

双击 `Pin To-Do_0.1.0_x64-setup.exe` → 选安装目录 → 安装。完成页有两个勾选：**创建桌面快捷方式**、**安装完直接运行**。装在当前用户目录下，不需要管理员权限；卸载用安装目录里的 `uninstall.exe` 或「设置 → 应用」。

需要 WebView2（Win11 一般自带）。没有时安装程序会联网拉微软官方 bootstrapper 装一次。

### 数据在哪

安装目录下 `data\dashboard1971-data.json`，单文件 JSON。设置里可导出 / 导入。卸载时如果勾了「删除应用数据」会把它一起删掉——**先导出**。

### 这一版有什么

- **桌面卡片层**：任务卡散布与静置胶囊两种样式，手动切换；窗口区域逐帧贴合可见形状，不挡点击、不闪标题栏。
- **9 套材质 × 昼夜两色**：材质决定圆角、纹理、阴影、字体，昼夜只决定颜色；调色台 39 项可调，每项都标注它画在界面哪里，含每套材质自己的弹窗背景透明度。
- **仪表盘**：今日概览（完成度环形图 + 四个统计格，随模块尺寸铺满）、时间账本（按分组分色堆叠）、热力图、月历、番茄钟、备忘录。
- **任务视图**：时间线 / 全部任务 / 分组，窄版面优先保留标题与日期。
- **提醒与自动化**：到点提醒（精确到秒）、作息分组到点自动完成、全局快捷键一键散布当前分组。
- **自然语言登记**（可选，默认关闭）：只发送你输入的那句话加当前任务列表；API 密钥只存 Windows 凭据管理器，不进数据文件、不随导出离开这台机器，请求由宿主进程发出。

体积：安装包 1.80 MB（lzma），安装后的 exe 5.3 MB，常驻内存约 116 MB。
